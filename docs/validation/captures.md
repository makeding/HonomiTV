# キャプチャ

## 移植元と契約

- `tsukumijima/KonomiTV` の `upstream/master` (`6b48bb48`) にあるキャプチャ実装を採用する。
- 視聴画面のキャプチャ、字幕・コメント合成、ファイル名設定、ブラウザ保存・クリップボード・サーバーアップロードを提供する。
- サーバー API は上流と同じ `POST /api/captures` の画像アップロードのみとする。
- 独自の保存画像一覧・検索・原図配信・削除・個人フォルダ・ブックマーク機能と `/captures/` の画面・ナビゲーションを廃止する。
- 旧ギャラリーのデータ移行・互換 API は実装しない。既存の画像や実 DB はこのソース変更では操作しない。
- このフォークの放送以外のチャンネルでは放送識別子の欠損を許容し、コメント機能がない場合はコメント付きキャプチャを拒否する。

## 検証

- クライアント ESLint / TypeScript、ルーターとキャプチャの直接回帰テスト。
- サーバー Ruff / Pyright と実ルーターへのアップロード HTTP テスト。
- 独自の画面・API・モデル・スキーマ・作成 migration の参照が残っていないことを確認する。
- ユーザー管理サーバーの起動・再起動は行わず、ローカル検証と実放送・実ブラウザの受入を区別する。
